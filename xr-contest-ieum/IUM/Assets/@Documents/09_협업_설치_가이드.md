# 협업자 설치 가이드

새 팀원이 빈 PC에서 프로젝트를 받아 실행·빌드까지 가는 전체 절차다. 터미널 명령은 그대로 복사해 쓰면 된다 (Windows / Git Bash 또는 PowerShell 기준).

## 1. 사전 준비

| 항목 | 버전 / 비고 |
|---|---|
| Unity Hub | 최신 |
| **Unity 에디터** | **6000.3.9f1** (버전 정확히 일치해야 함) + **Android Build Support** 모듈(OpenJDK·SDK·NDK 포함) |
| Git | 최신 (LFS 불필요) |
| GitHub 계정 | 저장소가 private이므로 리드(roy0206)에게 **콜라보레이터 초대**를 먼저 받아야 한다 |

Unity Hub → Installs → Install Editor → Archive에서 `6000.3.9f1`을 찾고, 모듈 선택 화면에서 `Android Build Support`(하위 항목 전부)를 체크한다.

## 2. 저장소 클론

```bash
git clone https://github.com/roy0206/XR_Contest.git
cd XR_Contest
```

Unity 프로젝트 루트는 저장소 바로 아래의 **`IUM`** 폴더다. Unity Hub → Add → `XR_Contest/IUM` 선택 → 6000.3.9f1로 연다. 첫 임포트는 수십 분 걸릴 수 있다.

## 3. AI 자격 증명 (수동 생성 — 각자 1회)

키 파일 자체는 저장소에 없다. 아래 두 파일을 **직접 만들어 내용을 그대로 붙여넣는다.** 이 파일들은 gitignore 대상이라 만들어도 커밋되지 않는다.

**`IUM/Assets/StreamingAssets/ai_secrets.json`** 생성:

```json
{
  "upstageApiKey": "<YOUR_API_KEY>",
  "googleApiKey": "",
  "googleAccessToken": "",
  "clovaClientId": "",
  "clovaClientSecret": "",
  "googleRefreshToken": "1//0eMfwdrKlmXPzCgYIARAAGA4SNwF-L9IrHH44NF9fzF10R1McYBQHYs4vRfqDmb1iShQUU9OC4BmGrZ2kLlqpTCsUfJmxCxtGtCY"
}
```

**`IUM/Assets/StreamingAssets/ai_oauth_client.json`** 생성:

```json
{"installed":{"client_id":"236134737061-6j29gvulk15rkcvramohsejs9dg1gfqu.apps.googleusercontent.com","project_id":"project-7c961d7d-d094-4c40-9b2","auth_uri":"https://accounts.google.com/o/oauth2/auth","token_uri":"https://oauth2.googleapis.com/token","auth_provider_x509_cert_url":"https://www.googleapis.com/oauth2/v1/certs","client_secret":"<YOUR_API_KEY>","redirect_uris":["http://localhost"]}}
```

터미널로 만들려면 (Git Bash, 저장소 루트에서):

```bash
cat > IUM/Assets/StreamingAssets/ai_secrets.json <<'EOF'

  "googleApiKey": "",

EOF

cat > IUM/Assets/StreamingAssets/ai_oauth_client.json <<'EOF'
{"installed":{"client_id":"236134737061-6j29gvulk15rkcvramohsejs9dg1gfqu.apps.googleusercontent.com","project_id":"project-7c961d7d-d094-4c40-9b2","auth_uri":"https://accounts.google.com/o/oauth2/auth","token_uri":"https://oauth2.googleapis.com/token","auth_provider_x509_cert_url":"https://www.googleapis.com/oauth2/v1/certs","client_secret":"<YOUR_API_KEY>","redirect_uris":["http://localhost"]}}

```

- 파일이 없거나 비어 있으면 게임은 죽지 않고 **목업 모드**(고정 응답·무음)로 동작한다.
- 이 문서는 저장소가 **private**인 것을 전제로 키를 담고 있다. 저장소를 공개로 전환하려면 이 문서를 먼저 이력에서 지우고 키를 재발급해야 한다. 키를 외부에 공유하지 말 것.

## 4. 로컬 STT(음성인식) 모델 설치 — 각자 1회

음성인식 모델(343MB)은 용량 문제로 저장소에 없다. 에디터에서 한 번만 내려받는다:

1. Unity 에디터 상단 메뉴 → **`IUM > AI > Install Local STT`**
2. 다운로드 완료 로그 확인 (`Assets/StreamingAssets/sherpa-onnx/`에 설치됨)

이걸 건너뛰면 음성인식만 목업으로 동작하고 나머지는 정상이다.

## 5. 에디터에서 실행 확인

`Assets/@Scenes/StartScene.unity`를 열고 Play. VR 기기 없이 데스크톱 조작으로 전 구간 진행 가능하다.

| 조작 | 키 |
|---|---|
| 이동 / 시점 | WASD / 마우스 우클릭 드래그 |
| 스냅턴 | Q · E |
| 오른손 잡기 | 마우스 좌클릭 (홀드) |
| 왼손 잡기 | F (홀드) |
| 상호작용(먹줄 찍기·망치 타격 등) | R |
| 이음이 호출(PTT) | T (누른 채 말하기) |
| 일시정지 | Esc |
| 대사 줄 스킵 (개발용) | Tab |
| 목표 강제 통과 (개발용) | Enter 탭 / 튜토리얼 전체 스킵은 Enter 3초 홀드 |

## 6. Quest용 APK 빌드

에디터를 **닫은 상태**에서:

```powershell
& "C:\Program Files\Unity\Hub\Editor\6000.3.9f1\Editor\Unity.exe" `
  -batchmode -nographics `
  -projectPath "<클론경로>\XR_Contest\IUM" `
  -buildTarget Android `
  -executeMethod ReleaseBuilder.BuildAndroid `
  -logFile "<클론경로>\XR_Contest\IUM\build_android.log"
```

- 결과물: `IUM/Builds/IUM.apk` (Addressables 콘텐츠 포함, 이 파일 하나로 완결)
- 실패 시 `build_android.log` 끝부분을 확인한다.
- 에디터 GUI에서 빌드하려면: Addressables Groups 창 → Build → New Build → 이후 File > Build Settings에서 Android 빌드.

## 7. Quest에 설치 (사이드로드)

Quest를 개발자 모드로 전환(Meta 모바일 앱 → 헤드셋 설정)하고 USB 연결 후:

```bash
adb devices          # 기기가 보이는지 확인 (헤드셋 안에서 USB 디버깅 '허용')
adb install -r IUM/Builds/IUM.apk
```

헤드셋 라이브러리 → **제공 출처 불명** 탭 → IUM 실행. 첫 실행 시 마이크 권한을 '허용'해야 이음이 음성 대화가 된다.

## 8. 협업 규칙 요약

- 씬·프리팹·ScriptableObject·ProjectSettings는 공용 자산 — 수정 전 리드와 협의.
- 개인 작업은 `Assets/@Developers/<이름>/` 아래에서 하고 통합 시 협의.
- 커밋은 기능 단위로 쪼개고, `Library`·`Temp`·`Builds`는 커밋하지 않는다(gitignore 처리됨).
- 상세 규칙: [00 문서 개요](00_문서_개요.md)와 저장소 루트 문서 참조.
