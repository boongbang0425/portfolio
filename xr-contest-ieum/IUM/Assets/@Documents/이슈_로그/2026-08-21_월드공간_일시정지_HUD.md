# 2026-08-21 · 월드 공간 일시정지 HUD

`Pause.prefab` / `Option.prefab`의 3D 메시를 UXML 일시정지·옵션 화면 대신 월드 공간 HUD로 붙이는 작업에서 발견한 사항이다.

두 프리팹은 이름이 전부 `개체_N`이고 콜라이더·스크립트·텍스트가 없는 순수 메시라, FBX 지오메트리를 정사영으로 렌더해 각 판의 정체를 판독한 뒤 매핑을 확정했다. 그 결과는 `PauseHudBuilder.cs`의 상수에 남아 있다.

## ISSUE-024 · 메인 화면 이동 확인 창이 프리팹에 없음

| 항목 | 내용 |
|---|---|
| 발견일 | 2026-08-21 |
| 상태 | 미해결 |
| 위치 | `Assets/@GameAssets/Prefabs/Pause.prefab`, `Assets/@Scripts/UI/World/PauseWorldMenu.cs:OnMainMenu` |
| 관련 | `Assets/@Documents/02_화면_흐름_튜토리얼.md` (F-019 2.4), `Assets/@UI/Pause/PauseMenu.uxml` |
| 증상 | Pause 프리팹의 상호작용 가능한 판은 `계속하기`·`옵션`·`공정 다시 시작`·`메인 화면으로` 넷뿐이다. `예`/`아니오` 확인 창에 해당하는 지오메트리가 없다. 기존 UXML 뷰에는 `pause-confirm-panel`이 있었으므로 월드 HUD로 옮기면서 확인 단계가 사라진다. |
| 영향 | `메인 화면으로`를 잘못 누르면 되돌릴 기회 없이 즉시 씬이 전환된다. 진행 저장은 공정 완료 시점에만 일어나므로 현재 공정의 부분 작업을 잃는다. UXML 뷰를 계속 쓰는 경로에서는 확인 창이 그대로 동작한다. |
| 조치 방향 | 확인 창 지오메트리를 프리팹에 추가하고 `PauseWorldMenu`에 `confirmPanel`·`confirmYes`·`confirmNo` 매핑 필드를 더한다. 지오메트리 추가 전까지의 임시 완화책으로는 `메인 화면으로`만 길게 눌러야 동작하게 하는 방법이 있다. 확인 창 유무는 기획 결정 사항이라 임의로 만들지 않았다. |

## ISSUE-026 · 패널 앞면 축이 임포트 결과에 대한 추정값

| 항목 | 내용 |
|---|---|
| 발견일 | 2026-08-21 |
| 상태 | 미해결 |
| 위치 | `Assets/@Scripts/UI/World/PauseWorldMenu.cs`의 `panelFacingLocal`, `panelUpLocal` |
| 관련 | `Assets/@Developers/RYU/Start/FixedUI/pause.fbx`, `Fixedoption.fbx` |
| 증상 | 프리팹의 레이어 노드가 X축 -90도 회전을 물고 있고 자식 메시는 전부 localPosition 0에 회전 없음이다. FBX 원본에서는 +Z가 패널 앞면인데, 이 회전을 거치면 루트 기준 +Y가 앞면이 된다. 이 계산으로 기본값을 `panelFacingLocal = +Y`, `panelUpLocal = -Z`로 두었으나 에디터에서 실제 확인하지는 못했다. |
| 영향 | 축이 틀렸다면 메뉴가 뒤집히거나 옆을 보고 뜬다. 버튼 눌림 방향도 같은 값에서 나오므로 판이 앞으로 튀어나올 수 있다. 두 값 모두 인스펙터 필드라 코드 수정 없이 고칠 수 있다. |
| 조치 방향 | 에디터에서 한 번 열어 보고 어긋나면 두 벡터를 맞춘다. 눌림 방향만 반대라면 `panelFacingLocal`의 부호를 뒤집는 것으로 함께 해결된다. |
